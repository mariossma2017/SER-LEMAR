Aderência dos seis meses

Arquivos anexados ficam neste navegador, em armazenamento local IndexedDB, não no GitHub nem em nuvem. Para manter os arquivos, não limpe os dados do site. O backup JSON existente não inclui anexos. Não use esta versão para evidências confidenciais em computadores compartilhados.

Dados e configurações

Os lançamentos ficam apenas no navegador utilizado. O GitHub Pages não sincroniza dados entre aparelhos. Exporte backups regularmente; para uso simultâneo por vários gestores será necessário conectar um banco de dados.

Metodologia

Aderência mensal: 40% execução + 30% qualidade de engajamento + 30% transformação. Qualidade e transformação recebem notas de 0 a 3. Farol verde ≥90%; amarelo ≥70%; vermelho <70%.

Conclusão do ciclo: 21 ações concluídas e evidenciadas até o sexto mês. As 3–5 ações prioritárias escolhidas para reporte ao cliente podem ser destacadas sem eliminar o compromisso interno das demais.
